# Sai Ganesh — 3D Developer Portfolio

A modern, interactive and fully responsive 3D portfolio website for **Sai Ganesh**.

The portfolio combines software development, AI/ML, web development, mobile development and cybersecurity interests with a highly interactive 3D user experience.

---

## 🚀 Tech Stack

### Frontend

- React
- Vite
- Three.js
- React Three Fiber
- React Three Drei
- Framer Motion
- Lucide React
- CSS3

### Backend

- Python
- Django
- Django REST Framework

### Database

- PostgreSQL
- SQLite for local development

### Deployment

- Render

---

## ✨ Features

- Interactive 3D background
- Three.js animated objects
- Floating 3D elements
- Animated particles
- Dynamic lighting
- Custom cursor
- Mouse-follow glow
- 3D hover effects
- Smooth scrolling
- Scroll-based animations
- Responsive design
- Animated project cards
- Interactive skill cards
- Education timeline
- Experience section
- Certifications section
- Contact form
- Django REST API
- PostgreSQL database support
- Django Admin panel
- Resume download
